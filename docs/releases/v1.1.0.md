# PCA9555 v1.1.0

Release date: 2026-05-17

This release is a documentation, diagnostics, and hardening release. It keeps the public API backward-compatible while tightening health semantics, Doxygen wording, CLI diagnostics, and release documentation.

## Highlights

- Cross-library diagnostics are easier to consume through `driverState()` and status-returning `getSettings(SettingsSnapshot&)`.
- `OFFLINE` behavior is now documented and tested as a latched state: normal public I2C operations do not touch the bus until `recover()` succeeds.
- Recovery internals now preserve the `OFFLINE` latch on failed recovery attempts that started offline.
- Bring-up CLI output now uses PCA9555 physical labels (`P00-P07`, `P10-P17`) while command arguments remain linear driver pins (`0-15`).
- Output-latch and input-sense wording is now consistent across CLI output, README, and Doxygen comments.

## Added

- `driverState()` alias for standardized diagnostics.
- `Status getSettings(SettingsSnapshot& out)` for callers that prefer status-returning diagnostic APIs.
- CLI version reporting with semantic version, encoded version, build metadata, and git metadata.
- Native tests covering latched `OFFLINE`, failed-write cache safety, invalid register guards, and neutral handling of transport `IN_PROGRESS`.

## Changed

- `stress_mix` now prints a start banner.
- Async `stress` now withholds the next prompt and queued-command processing until the active run completes.
- Stress progress lines keep color only on `ok=` and `fail=` result counts.
- `selftest` labels now use `PORT_0` / `PORT_1` for port APIs and include physical pin labels for linear pin examples.
- Doxyfile inputs now include the root implementation manual and docs tree, and `PROJECT_NUMBER` is aligned with `library.json`.
- README terminology now separates port registers, linear driver pins, physical PCA9555 labels, output latch state, input sense, and exact output patterns.

## Fixed

- Fixed bring-up CLI physical pin labels for Port 1. Linear pins 8-15 now display as `P10-P17`, not `P08-P15`.
- Fixed README Config Fields table rendering by moving explanatory text outside the table body.
- Removed duplicate Doxygen parameter sections from readback helper comments.
- Guarded raw tracked read helpers against zero-length reads before transport dispatch.
- Transport `IN_PROGRESS` statuses no longer count as health failures.
- Failed output, configuration, and polarity writes no longer mutate cached runtime shadows.

- `library.json` remains the version source of truth.
